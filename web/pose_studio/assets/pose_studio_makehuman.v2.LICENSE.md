`pose_studio_makehuman.v2.bin.gz` is a runtime-optimized derivative of
MakeHuman mesh, morph-target, rig, and weight assets.

The MakeHuman project releases these graphical assets under Creative Commons
CC0 1.0 Universal. The complete license text is preserved next to the binary
in `pose_studio_makehuman.v2.CC0-1.0.md`.

The generated binary does not change those license terms.
